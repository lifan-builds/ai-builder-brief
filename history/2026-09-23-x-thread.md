AI builders: two frontier releases reset model costs today, while open runtimes and new technical interviews sharpen how we build agents and evaluate their risks. Eight developments worth your time:

1/ Claude Opus 5.5 brings near-Fable capability to Opus pricing. Anthropic says most tasks cost 40% less than Opus 5; independent early tests found max-effort token use can erase that saving. Benchmark your own tasks. https://www.anthropic.com/claude-opus-5-5

2/ GPT-6 Sol and Luna halve GPT-5.6 promotional API prices. OpenAI also added better cache reuse across effort and tool changes. Re-run routing and per-task cost tests, especially for high-volume agents. https://openai.com/index/introducing-gpt-6-sol-and-luna/

3/ Google’s AX runtime makes agent infrastructure look more like Kubernetes: declarative workspaces, sandboxed tasks, network gateways, model policies, pause/resume, and inspection. It is early and likely to change. https://github.com/google/ax

4/ DeepSeek Harness v0.1.7-rc.1 adds plugin compatibility refusals, MCP resources, headless JSON events, remote workspaces, browser/computer use, automatic review, and Agent Team views. It remains a breaking-change preview. https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.1

5/ Google researcher John Platt explains ERA’s scientific search loop: define a score, keep a tree of notebook experiments, explore promising branches, and let a model mutate candidates. The hard part is still choosing a meaningful score. https://www.latent.space/p/john-platt

6/ Epoch AI’s JS Denain argues rising lab-agent usage is evidence of usefulness, but not yet proof of imminent self-sustaining AI research acceleration. Track throughput, spend, autonomy, and errors separately. https://www.interconnects.ai/p/debating-rsi-the-us-china-gap-and

7/ Evo contributor Eric Nguyen describes a genomic-model test using scored RNA sequences to prompt further optimization. It is a useful biosecurity evaluation idea, but the aptamer result is self-reported and not independently replicated here. https://www.latent.space/p/bio-security-is-an-ai-arms-race-eric

8/ Simon Willison’s llm 0.36 lets single-turn decision models declare that they cannot accept conversation history. It is a small but useful capability boundary for agent frameworks using models like Jev. https://simonwillison.net/2026/Sep/22/llm/
