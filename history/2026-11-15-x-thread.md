AI Builder Brief — Nov 15, 2026. Ten stories on leaked agent traces, knowing when to stay silent, useful coding memory, RoPE traps, code-based tools, agent-accessible UI, verifier rewards, open browsers, video APIs and full-duplex models. Sources below.

1/ Cursor's new breach report traces a Fireworks-exposed key through historical agent logs to a tampered extension cache. Up to 5,000 users potentially received malicious builds, not confirmed infections. Retained traces need real secret controls. https://cursor.com/blog/security-incident-update

2/ Deepnote tests when workplace agents should stay silent: 12 models, 50 synthetic situations. Correct silence averages 62.5%; needless interventions cost about 1.8x more. Test already-handled cases, not just whether an agent writes a good reply. https://deepnote.com/research/benchmark

3/ CoReMem values coding memory on the NEXT task, keeping code locations and executable checks. Its 27B system improves resolution 21.0%→25.7% with fewer total tokens. Author-run gains include actor training, not just a better memory file. https://arxiv.org/abs/2611.17316

4/ Raschka's new RoPE derivation exposes a checkpoint-porting trap: split-half and interleaved rotations match only with corresponding feature reordering. Test conventions before swapping code; longer position support alone proves no context extension. https://magazine.sebastianraschka.com/p/understanding-positional-embeddings

5/ Claude Code's experimental Code Mode batches tool calls in JavaScript and filters what the model reads. Native interactive terminal only, with major account/surface limits. Auto mode reviews the code, not every individual call. https://code.claude.com/docs/en/code-mode

6/ Vercel UI SDK lets agents read component state and invoke actions. A small same-form trial reports 10→2 calls and 9.6→3.7 seconds, five successes each. Promising beta; verify final state because callbacks can cancel changes without failing the call. https://ai.satyajit.si/articles/vercel-ui-sdk

7/ NOPO treats incomplete-verifier passes as unlabeled and learns from trusted failures. Author-run 4B/8B results improve pass@16, while GRPO still wins some pass@1 tests. Passing partial tests is not proof of correctness—or a safe positive reward. https://arxiv.org/abs/2611.17287

8/ Cloudflare open-sources Kitesurf: a CDP browser engine on Workers without a Chromium container. Hosted since August; the new event is Apache-2.0 source access. Compatibility is experimental, and cloud deployment needs a paid Workers plan. https://blog.cloudflare.com/kitesurf-open-source/

9/ Seedance 2.5 Flash now has documented API access, after coming-soon coverage. Supports 4–30s video at 480p/720p; a 5s 720p example costs 4.97 yuan vs 7.56 for full 2.5. Funded-account rules apply; paid generation not tested here. https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh

10/ inclusionAI ships Duo weights and real streaming branches for full-duplex audiovisual interaction. Research preview: default eight GPUs, one active session. Code is Apache-2.0; model terms exclude US/EU/UK/South Korea without separate licensing. https://github.com/inclusionAI/Duo
