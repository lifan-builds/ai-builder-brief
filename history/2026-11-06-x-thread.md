# X thread — November 6, 2026

AI Builder Brief — Nov 6, 2026. Ten stories: AI research acceleration, agent permissions and undo, privacy, Inkling, trace-driven tests, verified research, live apps, ERNIE weights, Conductor migration and iPhone automation. Sources and practical lessons below.

---

1/ METR estimates Anthropic’s benchmark-progress rate accelerated 1.9×, with AI assistance probably driving much of today’s gain. Major evidence is redacted; this is an uncertain assessment, not a causal experiment or an arrival-date forecast. https://metr.org/blog/2026-11-05-anthropic-ai-rd-acceleration-assessment/

---

2/ Dropbox puts agent permissions and credentials outside the VM, and ties file versions to conversations for targeted undo. If someone else edited a file, restoration makes a separate copy. A useful architecture for agents that change shared work. https://dropbox.tech/machine-learning/how-two-engineer-side-projects-became-the-agent-taking-action-inside-dropbox

---

3/ Claude Code’s renewed email-leak report now has published mitigation code. The privacy mod blocks a narrow User-Agent pattern in shell calls; its own docs exclude web/MCP tools and computed values. A version number alone is no privacy guarantee. https://github.com/anthropics/claude-code/blob/main/mods/privacy/README.md

---

4/ Inkling 2 Small is live on Tinker; Apache 2.0 weights are planned for next week after safety checks. Independent testing scores it 31, at about $1.18 and 21 minutes per task. Compare task cost and latency, not just cheap tokens. https://thinkingmachines.ai/news/inkling-2-small/

---

5/ NVIDIA’s new walkthrough turns traces into behavior tests, changes one harness rule, then checks hidden holdouts. The small example improves, but prompt compliance is no substitute for trusted-code enforcement. Try the loop on a real recurring failure. https://developer.nvidia.com/blog/use-nvidia-nemo-to-turn-agent-failures-into-tests-and-harness-fixes/

---

6/ TCSExam tests proofs, solvers, constructions and open conjectures with explicit checkers. Its index is not a percentage of research solved; complete proofs and intermediate progress count differently. Inspect the track scores and frozen references. https://arxiv.org/html/2611.07962v1

---

7/ Cursor cloud agents can now build and host apps with Postgres and SSO. Security checks precede explicit publishing; admins can inspect apps and unpublish them. Available on paid plans with cloud agents enabled; independent reliability data is limited. https://cursor.com/changelog/build-live-apps

---

8/ Baidu releases ERNIE-5.5-Flash-Base weights: 280B total, 14B active, trained on 33.5T tokens. This is a pretraining checkpoint for adaptation and RL, before instruction tuning. It uses a custom license; same-size leadership is vendor-reported. https://huggingface.co/baidu/ERNIE-5.5-Flash-Base

---

9/ Conductor is joining Meta. Cloud turns read-only Nov 13 and shuts down Nov 20, when deletion begins. Export or transfer workspaces and chats to local now; local updates last until early 2027. Test restoration before relying on an archive. https://www.conductor.build/announcement

---

10/ A new Poki user traced slow iPhone actions to readback and process startup. A resident-helper fix cut the maintainer’s six-tap test from 51.7s to 37.2s with verification on. Early, small-sample evidence: profile the bridge, not just the model. https://github.com/JosssphZhou/poki/issues/10
