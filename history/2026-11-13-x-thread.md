AI Builder Brief — Nov 13, 2026. Ten stories: measured agent loops, Inkling weights, automated red teams, structured instructions, self-hosted agents, AGENTS.md tests, Daybreak, native app workflows, cell-aware genomics and macOS VMs. Sources below.

1/ OpenRouter tested its localization loop: authored-check failures fell from 147/453 to 4/454. A separate judge caused retries without better final results, so it was removed. Self-reported, but a useful lesson: measure every check you add. https://openrouter.ai/blog/announcements/openrouter-in-8-languages/

2/ Inkling 2 Small weights are now downloadable under Apache 2.0, with serving and training integrations. This changes Nov 5's Tinker-only access. 594B total/17B active still needs about 500GB VRAM in NVFP4; “Small” isn't laptop-sized. https://huggingface.co/thinkingmachines/Inkling-2-Small

3/ Anthropic's Anvil beats human submissions on 23/24 bio test pairs, tying one. OpenAI separately shows gains from training on repeatable automated attacks. Test persistent adversaries; Anvil's privileged internal access limits direct comparisons. https://safeguards.anthropic.com/2026/automated-red-teaming/

4/ IBM's LLMON previews bind instructions to specific data using reserved tokens and addressable blocks. The 3B/8B weights and toolkit are public. Static injection tests improve, but a learned boundary still needs adaptive testing and tool controls. https://github.com/generative-computing/llmon

5/ Anthropic now offers self-hosted Managed Agents: run the service, agent loop and session storage yourself, beyond hosting sandboxes. Access is gated; inference still sends conversation data to your provider. Plan for operations and isolation. https://platform.claude.com/docs/en/managed-agents/self-hosted

6/ AAIF tested ~50 lines of AGENTS.md on one website: 7/9 to 9/9 correct runs, 36% fewer tokens, 26% lower estimated cost. Only 18 runs, one setup. The reusable part is the experiment: fresh checkouts, real tasks, builds and separate grading. https://aaif.io/blog/devex-for-your-agents-how-agents-md-cut-token-usage-and-cost

7/ Daybreak Red Team validates web-app vulnerabilities and checks patches; Defense Factory prepares fixes for engineer review. Early access/preview, not unrestricted rollout. Test the find–reproduce–fix loop on a bounded app before trusting coverage. https://openai.com/daybreak/red-team/

8/ ArtCraft's PhotoCraft makes native app behavior accessible through UI, CLI, JSON and MCP. New reporting and code show the workflow. It's alpha: feature breadth and professional readiness differ sharply; download claims are unverified. https://latent.space/p/artcraft/

9/ AlphaGenome 2 conditions DNA predictions on cell state, including new single-cell data without retraining. DeepMind reports higher variant recall. Noncommercial research API is available; commercial access is preview, and this isn't clinical validation. https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/

10/ Vercel Agent Desktop v1.3 adds clonable macOS VMs: separate disks and desktops, then headless starts. Useful for repeatable UI work. Guests share host-network reach, so this isn't a boundary for untrusted code; initial setup is manual. https://github.com/vercel-labs/agent-desktop/releases/tag/v1.3.0
