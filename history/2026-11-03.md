## Top 10

1. **MIT researchers edit Qwen’s weights to remove loops without gradient training** — **November 2 original experiments and publication**. GPT-6 Astra inspected Qwen3.5-0.8B with a budget of 50 batched forward passes, then altered 131,072 weights in two MLPs; author-reported MATH-500 rose from 7.9% to 48.1%, and a Hugging Face rerun scored 51.0% on the edited checkpoint. The mechanism removes a direction associated with repetitive reasoning, rather than demonstrating general acquisition of mathematical ability: edits to a non-looping Gemma model produced no established gain. Try targeted weight debugging with held-out tasks and explicit inference budgets. Published logs omit earlier prompt trials; the rerun’s baseline check covered only 25 problems. [Experiments and negative results](https://rikiyat.github.io/blog/weight-space-programming/) · [Checkpoint, hash verification and rerun](https://huggingface.co/RikiyaT/Qwen3.5-0.8B-weight-space-programming).

2. **OpenAI explains how Pando removes Git bottlenecks under coding-agent load** — **November 2 engineering retrospective; migration predates publication**. OpenAI reports Pando now serves all development in its monorepo, cutting median push latency nearly 80% while delivering almost a petabyte daily. The newly explained design coordinates branches independently and reuses immutable packfiles, trading repository-wide snapshots and minimal transfers for parallel writes and cacheable reads; individual branches retain ordered updates. Measure push-to-fetch latency and repeated pack generation before assuming agents require a different version-control system. This is one organization’s production account, not ecosystem adoption telemetry; the interactive comparison is explicitly synthetic, Pando is not publicly released, and public Git patches are the immediately inspectable artifact. [Architecture, deployment and tradeoffs](https://openai.com/index/scaling-git-at-openai/) · [Public Git changes](https://github.com/openai/git).

3. **Phil Schmid explains how Code Mode replaces repeated tool-call round trips** — **November 1 original technical synthesis**. Schmid shows how an agent can receive typed tool interfaces, write one orchestration script, filter intermediate results in memory and return only useful output, rather than repeatedly putting raw API responses into model context. His example chains project discovery, parallel issue queries and conditional actions; the host bridge can retain credentials and enforce permission checks on each underlying call. Prototype one repeated workflow and compare latency, context use and recoverability against ordinary tool calling. This is a new explanation of existing implementations, not proof of a fresh adoption surge or universal superiority; its illustrative Node VM example is not a sufficient security boundary. [Complete mechanism and examples](https://www.philschmid.de/code-mode) · [Earlier Cloudflare implementation](https://blog.cloudflare.com/code-mode/).

4. **Anthropic’s amended filing exposes expensive compute and uncertain research acceleration** — **November 2 S-1/A; financial period ended September 30**. Quarterly revenue reached $16.956 billion, but a $567 million operating loss replaced Q2’s $974 million profit; Anthropic attributes pressure to $5 billion of short-term compute and $2 billion of noncash donation charges. The $23.3 billion net loss is largely financing revaluation, not equivalent cash burn. The same filing warns future models may soon cross its AI-driven research-acceleration threshold, while explicitly designating no current model above it. Builders should separate model capability, serving economics and provider risk: neither revenue growth nor a risk disclosure establishes sustainable pricing or achieved recursive self-improvement. [Primary filing](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm) · [AP financial reporting](https://abcnews.com/Technology/wireStory/anthropic-posts-17b-quarterly-revenue-losses-continue-fresh-137775250) · [TechCrunch on the new risk language](https://techcrunch.com/2026/11/02/anthropic-warns-that-its-very-close-to-rsi-capability-aka-self-building-ai/).

5. **Anthropic releases FlashProve to verify inference against committed model weights** — **November 2 research release**. FlashProve supplies code, a protocol and Lean proofs for checking that output matches a committed model without exposing its weights. Anthropic reports roughly 110 tokens/second on 4-bit Llama 4 Maverick using one H100, but proving costs about 70–95 times ordinary inference GPU time. Crucially, this is post-hoc verification of an integer model’s greedy choices over at most 1,024 tokens; sampled or floating-point replies may differ, and the fast C++ verifier lacks the Lean verifier’s formal guarantee. Treat it as an auditable provenance prototype to investigate, not a deployable guarantee for arbitrary frontier API traffic. [Research and limitations](https://www.anthropic.com/research/provable-inference) · [Released implementation and verification routes](https://github.com/anthropics/FlashProve).

6. **Hindsight releases small decision models to reduce agent-memory generation costs** — **November 3 models, analysis and v1.2.0 release; repository created October 2025**. A 0.8B decision model returns typed judgments and probabilities for memory relevance, consolidation and refresh decisions, leaving generative models to write changed observations and final answers. Vendor evaluations reduce Gemini-3.8-Flash cost from $147 to $61 per thousand cases, but its reflect score slips from 94.1% to 91.2%; some cheaper backends become more expensive. Test operation-specific quality and cost before enabling pruning or replacing model calls. Weights and integration artifacts are available, with decisions disabled until configured; results use the vendor’s cases and model judge, measure model-call time rather than end-to-end latency, and do not establish adoption. [Mechanisms, benchmarks and regressions](https://hindsight.vectorize.io/blog/2026/11/03/hindsight-models) · [Decision-model card](https://huggingface.co/hindsight-ai/hs-decide-1-flash) · [Release](https://github.com/vectorize-io/hindsight/releases/tag/v1.2.0).

7. **IBM’s CUGA comparison shows harness configuration can dominate multi-app completion** — **November 3 experiment and explanation; CUGA repository created September 2025**. With GLM-5.3-flash held constant, IBM reports 73/90 AppWorld tasks completed by CUGA, 42 by Hermes and 27 by Deep Agents; all three variants passed in 20/30, 8/30 and 2/30 scenarios respectively. CUGA decomposes work by app, narrows tools, executes Python, checks mutations and audits missed pagination. Reproduce against your own tasks and tune competing harnesses before choosing by model leaderboard alone. This is a vendor-run, one-attempt comparison with unequal task-specific configuration; policy enforcement was not enabled, so the completion scores do not validate its separate governance claims or demonstrate production migration. [Full setup and limitations](https://huggingface.co/blog/ibm-research/cuga-harness) · [AppWorld adapters and configurations](https://github.com/cuga-project/harbor-eval/tree/main/adapters/appworld).

8. **Claude Code adds blocking hooks and clearer controls for unattended runs** — **November 3, 01:25 UTC v2.1.317 release**. The release adds an SDK hook option, `onFailure: "block"`, so a failing callback can stop the action, plus warnings about unexpected connectors on scheduled tasks and checks before tools send the account email address to the network. It also corrects headless runs reporting success after losing transcript or configuration writes, although full NFS exports may still escape detection. Exercise failed callbacks, storage exhaustion and scheduled-task connector setup before relying on unattended execution. These are inspectable release claims, not independently measured incident reductions; the blocking behavior is an option to configure, not evidence that every existing hook now fails closed. [Official release and complete conditions](https://github.com/anthropics/claude-code/releases/tag/v2.1.317).

9. **vLLM advisories reveal serving failures beyond ordinary model-output validation checks** — **November 2, 19:48–19:50 UTC disclosures; patched version listed as 0.33.0**. One advisory describes a single unauthenticated request crashing the shared engine when `--skip-tokenizer-init` bypasses vocabulary checks; another shows aggregate image processing exhausting frontend resources before prompt admission. A third documents untrusted model configuration redirecting checkpoint and tokenizer loading, even with remote code disabled. Audit deployment modes, authenticate inference access and verify the patched version before exposing shared serving. Conditions differ: image exhaustion requires permitted multimodal inputs, its bounded demonstration did not crash the process, and checkpoint redirection requires an operator to load a malicious artifact. No exploitation prevalence was established. [Token-ID engine crash](https://github.com/vllm-project/vllm/security/advisories/GHSA-q9v9-qpjp-fc24) · [Media-budget exhaustion](https://github.com/vllm-project/vllm/security/advisories/GHSA-5r3c-5x4v-8gjh) · [Model-loading redirection](https://github.com/vllm-project/vllm/security/advisories/GHSA-qrj2-j723-m6w8).

10. **Legora explains how privacy constraints reshape agent evaluation and product design** — **November 2 newly published CTO interview and technical account**. Jacob Lauritzen describes testing legal agents in synthetic worlds containing large document rooms while categorizing production failures into roughly 10–20 types, rather than freely inspecting confidential client traces. Task-and-practice-area evaluations expose model regressions; tabular review starts with ten rows so users can repair instructions before scaling toward a million cells. Build representative worlds and compact failure taxonomies when raw traces are unavailable, and test small batches before costly fan-out. This is detailed practitioner testimony, not a public evaluation corpus or independently audited reliability result; merely removing names is not presented as sufficient anonymization. [Full interview and transcript](https://latent.space/p/building-ai-for-lawyers-jacob-lauritzen-cto-of-legora/) · [Supporting sandbox implementation account](https://modal.com/blog/how-legora-runs-thousand-scale-parallel-agent-evals-on-modal-sandboxes).
