AI Builder Brief - Nov 17, 2026. Ten stories on benchmark leakage, GPT-6.2, protected verification, agent skills, lost requirements, inference routing, hybrid caches, Qwen4, vulnerability deadlines and independent assessment. Sources below.

1/ Benchleaking audits four base models across 20 benchmarks. ERNIE-5.5-Flash-Base reproduces 96.3% of HumanEval; zeroing detected leaks drops its suite score 85.17 to 68.55. Author-run audit, not proof of deliberate cheating. https://arxiv.org/abs/2611.21315

2/ GPT-6.2 Astra and Sol are live. Astra API input/output prices fall 20%, but its system card reports more omitted blockers in adversarial tests; Codex prompting mitigates this, direct API requests need their own checks. https://openai.com/index/introducing-gpt-6-2-astra-sol/

3/ Claude Code's team keeps review rules on the base branch, binds reviews to commits and tests reviewers against historical incidents plus clean changes. Protect the checker before scaling agent delegation. A concrete new engineering account. https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/

4/ Together merged 14 skills and initially got worse: 90.3% to 75% completion, about 2x cost. A smaller router, selective references and repaired examples/errors reached 70/72. Small vendor-run suite; unusually useful failure analysis. https://www.together.ai/blog/how-we-do-agent-evals-at-together-ai

5/ SWE-CoWork's simulated workplaces expose a handoff gap. Giving Astra complete requirements raises partial test success 62.91% to 78.84%, but full-task success stays 7.92%. Track requirements through implementation and verification. https://arxiv.org/abs/2611.20218

6/ Hugging Face now routes language-model Inference Providers through OpenRouter. Breaking change: custom language-model provider keys are gone; HF handles billing. Check provider permissions and use a stable session ID for cache locality. https://huggingface.co/blog/openrouter

7/ Quail saves recurrent state and convolution buffers alongside KV caches for hybrid models. Its 3.2x author-reported gain on 46 AI-SQL queries comes from recomputing less, not faster kernels. A useful state-accounting lesson. https://fsdatalab.github.io/blog/hybrid-models-in-quail/

8/ Qwen4-Max moves from Token Plan preview to a general API: 1M context, text/image/video input, tool calls and structured outputs. QwenCloud lists $1.50 input/$4.50 output per MTok. Weights remain private; test whole-job cost. https://docs.qwencloud.com/changelog/models

9/ Anthropic cuts high/critical vulnerability disclosure from 90 to 30 days for new reports starting Jan 1, 2027; others get 45 days. Human-reviewed findings only, with hard-to-deploy exceptions. Maintainers need faster triage. https://www.anthropic.com/research/coordinated-vulnerability-disclosure-timelines

10/ OpenAI signs four embedded-assessor pilots. Apollo will place six evaluators inside for four months, but says access/disclosure still fall short of its full standard. Read the limits alongside future safety findings. https://www.apolloresearch.ai/blog/pilot-towards-embedded-evaluations
