# X thread — November 2, 2026

AI Builder Brief — Nov 2, 2026. Today’s eight: long-reasoning memory, LongCat-2.5, honest agent evals, CI under agent load, desktop automation, mathematical research, Grok Bot meters and AI-adoption measurement. Sources and practical lessons below.

1/ Short-answer benchmarks can hide memory failures. A new equal-memory Bifocal experiment improves long-answer math, but the overall gain is small and uncertain. Test long generated reasoning before choosing an attention architecture. https://huggingface.co/blog/sirluk/sliding-window-beats-linear-attention

2/ LongCat-2.5 is now on Meituan’s API: native visual tokens, longer agent training and 1M context. Weights remain unavailable. Vendor benchmarks look stronger, but need replication in your own coding harness. https://longcat.ai/blog/longcat-2.5/

3/ AiSOC found 72 eval calls with no serving-model attribution. Its new release tracks who actually answered and stops merging unrelated alerts; one reduction result falls from 42.6% to 24.5%. Audit aliases, fallbacks and denominators. https://github.com/beenuar/AiSOC/releases/tag/v21.0.0

4/ One team reached 694 weekly PRs, mostly agent-written. A new retrospective explains fresh CI VMs on a €99/month server, short warm-pool waits and painful busy-hour contention. Measure arrivals before buying capacity. https://brunoj.com/our-coding-agents-outgrew-githubs-runners/

5/ Agent Desktop’s v1.0.2 records its move to Vercel Labs and fixes macOS permission setup. Native accessibility trees and snapshot-scoped refs offer another automation route; dispatched actions still need result checks. https://github.com/vercel-labs/agent-desktop/releases/tag/v1.0.2

6/ Frank Calegari proposes evaluating mathematical work as potentially AI-assisted, rewarding understanding and useful new questions. His new essay turns the debate into concrete changes to hiring, journals and training. https://terrytao.wordpress.com/2026/11/01/mathematics-has-changed-lets-act-like-it/

7/ Grok Bot users report work blocked by sudden meter jumps; some readings are now corrected. Musk says serving costs exceeded sustainable revenue. That does not establish a universal deliberate quota cut. Export usage and cap overflow. https://x.com/elonmusk/status/2116992258520064397

8/ Willison’s new Census analysis shows how survey wording changes distort AI-adoption comparisons. Broader business-use questions broke the old series; another terminology change has results pending. Version your measurement definitions. https://simonwillison.net/2026/Nov/2/census-bureau-super-intelligence/
