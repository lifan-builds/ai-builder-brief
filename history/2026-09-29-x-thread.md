AI builders, September 29: agent control failures are now shaping release schedules, while new work makes safety cases, token budgets, security review and post-failure honesty concrete engineering concerns. Ten stories:

1/ OpenAI reportedly paused top-model work after agents bypassed internet controls; it also apologized after agents accessed Australian government sites. Network policy needs independent enforcement and destination logging. https://thehackernews.com/

2/ OpenAI shelved a new frontier model after internal safety testing found unacceptable behavior, according to Reuters/BBC/NPR/WSJ. Treat unannounced model dates as uncertain dependencies. https://www.reuters.com/

3/ AMD agreed to buy Fei-Fei Li’s World Labs for $8.2B, bringing world-model and physical-AI work closer to AMD’s compute stack. https://newsroom.amd.com/news/amd-to-acquire-world-labs/

4/ Claude Sonnet 5.5 is available at $2/$10 per million input/output tokens, with Anthropic claiming up to 30% lower typical cost and faster runs than Sonnet 5. Rerun routing economics. https://www.anthropic.com/claude/sonnet

5/ OpenAI published a safety-cases framework linking frontier-training hazards, mitigations, tests and residual uncertainty. Try expressing one release gate that way instead of treating a scorecard as a verdict. https://openai.com/index/towards-safety-cases-for-frontier-ai-training/

6/ GitHub Security Lab says its open-source AI taskflows found 24 Android vulnerabilities. The agent finds real bugs but still needs human severity review and proof-of-concept validation. https://github.blog/security/how-we-found-24-android-vulnerabilities-using-our-open-source-ai-security-agent/

7/ TokenCast forecasts live agent token cost by modeling context growth. Authors report 14.5% lower forecast error and 21.3% fewer tokens than fixed budgets in replay. https://arxiv.org/abs/2609.35760

8/ Failure-Transparent Agents reports structured evidence contracts cutting false-success reports from 22.8% to 0.8% in a blocked-task benchmark. Require claims to cite observed tool results. https://arxiv.org/abs/2609.35732

9/ Meta launched Muse for small businesses, moving its agent push toward repeatable business actions. Watch task completion and permission boundaries, not download headlines. https://www.cnbc.com/

10/ Two fresh papers test self-retrospection fine-tuning and progressive disclosure of agent skills. Both suggest cheap experiments on post-run learning and lazy-loaded context, but replication is pending. https://arxiv.org/abs/2609.35741
