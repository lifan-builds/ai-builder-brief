# Daily briefing history

The scheduled Daily AI News Top 10 job writes one Markdown file per completed
run here, named `YYYY-MM-DD.md`. Each file contains the exact text-only
briefing returned for that date, including the watchlist, source-panel activity,
and changes from the previous run.

The archive begins with runs after this policy change. Earlier runs have
summary records in the automation memory, but their complete briefing text was
not retained as repo files.
