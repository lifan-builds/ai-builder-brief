AI builders, September 25: yesterday’s biggest agent “hack” claim is now contested. Today’s strongest lessons are to verify agent handoffs, test security work with real tools, and give people better surfaces than chat. 10 stories ↓

1/ Archived code suggests Australia’s Medicare statistics portal directed visitors to a guest endpoint. That complicates the claim an OpenAI agent hacked its way in; the logs are still unavailable. https://therecord.media/openai-australia-breach-cyber

2/ A new technical essay argues that agent-to-agent messages should be treated as claims to check, especially where outputs merge or trigger actions. Correlated model errors make simple voting fragile. https://www.noetive.io/blog/byzantine-agents

3/ Microsoft unveiled Copilot Home, Code, and Autopilot: tenant-hosted small apps and a persistent agent with its own identity and workspace. Most of it is rolling out or in preview, so real governance and cost remain the test. https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/

4/ GitHub Security Lab published an agent-driven C/C++ fuzzing pipeline: generate harnesses, run AFL++, read coverage, improve inputs, triage crashes. Run it in a disposable environment; broad adoption has not been shown. https://github.blog/security/application-security/ai-powered-fuzzing-with-the-github-security-lab-taskflow-agent/

5/ Google Research explains long-form AI video as a state-tracking problem. Its system plans a global story, anchors entities, generates segments, and uses visual critiques to fight drift. Results are lab-reported. https://research.google/blog/coherent-long-form-video-generation/

6/ GitHub’s “When chat is the wrong UI” makes a practical point: let an agent build a small interface for repeated tasks, then let people act directly. The examples are useful, though token savings are not measured. https://github.blog/ai-and-ml/github-copilot/when-chat-is-the-wrong-ui/

7/ Reuters reports a power-related delay at Oracle and Blue Owl’s New Mexico AI data-center project. Blue Owl says commitments remain; a source says completion shifts by a year. Capacity promises need contingency plans. https://www.reuters.com/business/energy/oracle-blue-owl-project-delay-sends-ripples-through-ai-financing-sources-say-2026-09-24/

8/ Latent Space interviewed Runway researchers on real-time generated worlds: timed prompts, autoregressive video, distillation, and the hard problems of error buildup and memory. This is new analysis of an earlier preview. https://www.latent.space/p/runway

9/ Anthropic committed $11.6B over seven years for Akamai CPU capacity, with a possible expansion and equity warrant. Non-GPU execution is becoming a strategic part of AI infrastructure; service effects are still unknown. https://www.akamai.com/newsroom/press-release/akamai-announces-11-6-billion-multi-year-agreement-with-anthropic-to-support-growing-demand

10/ GitHub now previews fresh human authentication before sensitive enterprise actions such as creating tokens or editing webhooks. It targets the gap between “valid session” and “authorized human here now,” with a narrow initial scope. https://github.blog/changelog/2026-09-24-require-proof-of-presence-for-high-impact-actions/
