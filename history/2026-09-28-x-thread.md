AI builders, September 28: agent safety is becoming an enforceable runtime problem. Today's other useful shifts challenge assumptions about coding-agent docs, larger agent teams, model purchasing choices, and evals. Ten stories worth your time:

1/ NVIDIA launched Open Agent Safety Platform: OpenShell mediates files, network and credentials outside the agent; a BlueField watchdog is a reference design. The runtime is available, but field efficacy is unproven. https://nvidianews.nvidia.com/news/open-agent-safety-platform

2/ A new coding-agent study made compact code descriptions more complete, then found they didn't improve issue resolution when source was already present. Test whether your docs add missing contracts or repeat readable code. https://arxiv.org/abs/2609.31587

3/ Holo4 puts GUI, code, MCP and API use in one model, with weights and replayable trajectories. Its 27B score is 61.7% on the harder OSWorld 2.0 in the vendor's harness; check tasks and noncommercial license before use. https://hcompany.ai/newsroom/holo4

4/ PriceBench finds purchasing agents have model-specific preferences: 28 models chose among 3,600 hotel tasks, with mean booked price ranging from $247 to $393. Audit choice policy and listing-order effects before letting agents spend. https://arxiv.org/abs/2609.31468

5/ A study of 13 open models finds larger agent teams can contain more correct answers without voting finding them. One peer revision captured much of the gain; shared bias limited averaging. Benchmark your aggregation rule, not team size alone. https://arxiv.org/abs/2609.31563

6/ ESPnet released YODAS v3: 1.1 million hours of open multilingual speech, with timestamps, translations and much genuine multichannel audio. Sample quality and provenance before committing to a 60 TB training input. https://huggingface.co/blog/espnet/yodasv3

7/ EffectMatch tests a sharper agent approval boundary: compare actual persistent changes with the approved post-state before commit or handoff. Its 206-task results are author-reported, but the extra-write failure mode is worth testing. https://arxiv.org/abs/2609.31301

8/ ReVerPi's context-compression audit shows how 15 completed pairs can hide 12 capped boundary runs. Report all assigned trials, failures, turns and token distributions; a success tie among finishers is not a system-wide tie. https://arxiv.org/abs/2609.31381

9/ Confidence supervision reduced reasoning tokens by up to 25% at matched accuracy in author tests, without an inference-time stop rule. Interesting for teams training models; it isn't a hosted-API switch. https://arxiv.org/abs/2609.31619

10/ OpenRig's September releases refine persistent Claude Code/Codex teams, including keeping managed Claude instructions out of tracked CLAUDE.md. GitHub reported 781 stars today; attention isn't proof of production adoption. https://github.com/mvschwarz/openrig/releases/tag/v0.5.16
