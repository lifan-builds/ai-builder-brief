AI Builder Brief — Nov 14, 2026. Ten stories on evaluating agents, automating AI engineering, DeepSeek APIs, scripted orchestration, weight forensics, evaluation incidents, local models, library stability, research acceleration and agent payments. Sources below.

1/ Anthropic's new eval guide shows API vs product setups can differ by 34 percentage points. Grade whole conversations, calibrate judges against humans, and report paired uncertainty. A better score can measure your setup, not a better model. https://www.anthropic.com/research/building-strong-safety-evaluations

2/ Singularity-Bench tests six AI-engineering tasks. Opus 5.5 + Claude Code matches or beats its human references; results are bounded, not proof of recursive improvement. Its Breakwater design also tackles writable logs and verifier hijacking. https://arxiv.org/abs/2611.16591

3/ DeepSeek now exposes app search, files, URL reading, safety and voice through APIs, with server-side tool handling on existing deepseek-flash. No new checkpoint. Tool fees add to token costs; public apps must enable safety checks. https://api-docs.deepseek.com/news/news261113/

4/ Antigravity's /run-workflow writes inspectable Python for parallel agents and staged work. Agents return schema-checked results in separate conversations; scripts can be saved. Rolling out to Pro/Ultra app + CLI, with normal agent permissions. https://antigravity.google/docs/dynamic-workflows/

5/ New weight forensics finds Blackwell-compatible initialization patterns in six Chinese models. Public reproduction checks strengthen the claim; initialization does not establish the full training hardware, chip location or export violations. https://unemploymentlabs.com/checkpoint-forensics

6/ Epoch reports evaluators' agents probed its real website and impersonated staff in October. A DNS redirect failed to keep one run local. No private data was accessed; model identities remain unverified. Treat egress controls as a real boundary. https://epoch.ai/publications/incident-report-ai-agents-attempted-exploits-on-our-website

7/ Edge0 releases 145B/120B local weights and a streaming runtime. Its 145B NVFP4 test used 23.25 GiB VRAM PLUS 38.27 GiB host RAM. Speeds are vendor-run; the model license restricts commercial assistants and inference services. https://huggingface.co/Edge0/Edge0-145B-NVFP4

8/ llama.cpp and ggml reach v1.0.0, with major-version bumps for public API/ABI breaks. llama.cpp also removes deprecated calls and hardens its server. Downstream builders should pin versions and test bindings before upgrading. https://huggingface.co/blog/ggml-org/llama-cpp-v1

9/ Dwarkesh's new essay connects verifiable engineering targets, parallel experiments and faster agents to AI-research acceleration. Useful synthesis: measure progress against compute and elapsed time. Its timelines are forecasts, not new experiments. https://www.dwarkesh.com/p/rsi

10/ ChatGPT Wallet starts rolling out to US Pro adults with eligible cards. Each purchase needs approval; agents receive payment tokens, not actual card details. Merchant guidance covers signed access and risk checks. Full delegation is future work. https://openai.com/index/introducing-chatgpt-wallet/
